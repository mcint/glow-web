## 4. Collapse-at-rest / expand-on-hover for the segmented chips
**Queued for a near-future patch** (e.g. v0.6.5 / v0.7.x). Refines the v0.6.1
segmented filter chips. At rest, collapse to a single compact line showing the
active label + all three counts inline:

```
{md 14 | +19 | +16}
```

On mouseover, expand to the full vertical per-stratum labels + counts:

```
| {md 14}    |
| {+text +19}|
| {+all +16} |
```

So at rest only the current aperture's label shows (with the marginal counts
still visible inline); hover reveals each stratum's full name. Builds on
`paintStrata()` / `.seg` / `.is-on` already in place (`scripts.html.tmpl`,
`style.html.tmpl`). The current build keeps all labels always-visible; this
trades that for a tighter at-rest footprint. Same for both class and hidden
chips.
