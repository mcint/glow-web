# 2026-05-07 — glow-web v0 build session

A long single-day session that took glow-web from empty directory to a
~20-commit private GitHub repo. This is a working note, not a spec; it
captures what shipped, what was decided (and why), and what's queued.

## Built today

In rough order:

1. **Scaffold** — Go module, SPEC, .gitignore, README. Initial vision:
   one binary, three faces (web/tui/slice) over a shared goldmark AST.
2. **`internal/mdcore`** — single goldmark config (GFM + footnote +
   typographer + auto heading IDs) shared by every output adapter.
3. **`internal/render` HTML adapter** — `render.HTML(src) → []byte`
   with snapshot test on `testdata/sample.md`.
4. **`internal/slice`** — heading-path semantic slicing with
   sibling-closes-section semantics. The differentiated CLI surface.
5. **`internal/web` v0** — minimal single-file viewer with embedded
   stylesheet template.
6. **CLI dispatcher** — stdlib flag, intermixed-args shim so
   `cmd PATH --flag` works either way.
7. **`internal/version`** — runtime build identification with VCS
   revision; surfaces in footer + `glow-web version` subcommand.
8. **`internal/walk`** — gitignore-aware markdown discovery; security
   boundary for dir-mode serving.
9. **Web refactor — dir mode** — `Server` struct, file vs dir
   autodetect, per-page templates (style/footer/view/index/edit
   partials), action buttons (Raw/Download/Edit), URL prefix mount,
   home-relative footer paths.
10. **Edit page + live preview + save** — split-pane textarea + 250ms
    debounced POST `/_/render`, save POST to same URL, Cmd-S binding,
    `--readonly` gates both.
11. **Hybrid markup view** — `render.HTMLMarkup` emits source-visible
    rendering with muted markers; `?view=markup` toggle and `--markup`
    server default.
12. **Listener URL polish** — clickable URLs in the boot notice;
    wildcard binds expand to localhost + LAN IPv4s; `net.Listen` then
    `http.Serve` so `--addr :0` reflects the real port.
13. **Click-navigable breadcrumbs + `?prefix=` filter** — bar replaced
    with `project / sub / file` crumb nav; clicking a directory crumb
    lands on the index filtered to that prefix.
14. **Intra-project link rewriting** — relative `[foo](../sub/foo.md)`
    becomes a navigable href; walk-result allowlist gates rewriting.
15. **⌘K command palette + index fuzzy filter** — fzf-style scoring,
    `/_/files` JSON endpoint, gated by `--palette`.
16. **Specs reorg** — `SPEC.md` → `specs/spec.md`,
    `docs/notes/feature-toggles.md` → `specs/feature-toggles.md`.
17. **Loopback default** — `--addr` default became `127.0.0.1:8080`
    (was wildcard `:8080`); RFC 5737 TEST-NET ranges in tests.
18. **README expansion** — `go install` path; charmbracelet/glow link;
    five Chromium-headless screenshots committed.
19. **Dark mode** — auto/light/dark UI toggle with FOUC-free init
    script; `--theme` flag for server-seeded default.
20. **Persistent sidebar + scroll memory** — palette overlay became
    a left-anchored sticky sidebar; per-file scroll position in
    localStorage keyed by pathname.
21. **localStorage namespacing** — all keys prefixed with
    `glow-<8hex>-` (FNV-1a hash of absolute root) so two instances
    on the same browser origin can't trample each other's state.
22. **Title prefix** — `<title>` rendered as `<doc> · <prefix>` with
    `--title-prefix=auto` expanding to `glow-web:<port>`. Reverse-
    proxy story explicit in spec; `--title-prefix-port=auto|never|always`
    sub-flag for port handling.
23. **Makefile + screenshot script** — `make check` is the commit
    gate; `make screenshots` regenerates README PNGs via playwright +
    system chromium (no playwright-managed browser download).

## Decisions worth remembering

- **Default-safe over default-flexible.** Loopback bind, gitignore on,
  link rewriting allowlisted, localStorage namespaced — every default
  errs toward "safe and unsurprising," with a single explicit flag to
  loosen each one.
- **Walk-result list as the security boundary.** Not just for serving,
  but also for link rewriting and `/_/files`. One allowlist gates every
  surface that could leak a gitignored file.
- **Server-side render for live preview.** The edit page POSTs to
  `/_/render` instead of running a JS markdown library, so the preview
  is byte-for-byte identical to the read-only view. No client-side
  parser dependency.
- **Sentinel + literal for TitlePrefix.** "auto" expands; anything
  else passes through. Keeps the policy in the user's hands without
  growing a template-token mini-language.
- **localStorage over cookies** for all UI state. No server-side
  session, no cross-origin sharing, namespaced by hashed root so
  multiple projects on `localhost:*` don't collide.
- **Spec alongside features.** Every user-visible surface added today
  shipped with a spec note in the same commit (or the next), per the
  global CLAUDE.md spec-first norm. `specs/feature-toggles.md` is the
  meta-memo for when (not yet) we promote bool flags to a Config struct.

## Surface as of end-of-session

```
glow-web web PATH [flags]                        serve file OR directory
    --addr 127.0.0.1:8080                        loopback default; ":port" → LAN
    --url-prefix /docs
    --gitignore=true
    --ignore-files .rgignore
    --readonly
    --markup                                     hybrid markup as default view
    --palette=true                               ⌘K sidebar
    --theme auto                                 auto | light | dark
    --title-prefix auto                          "<doc> · <prefix>"; auto = "glow-web:<port>"
    --title-prefix-port auto                     auto | never | always

glow-web slice PATH --heading "Foo / Bar"
glow-web render PATH --format html|markup
glow-web version
```
